# Mindscape visual redesign

- Added original crimson castle artwork at `public/art/crimson-castle.png`.
- Added Aria, a female scholar-guide character, at `public/art/aria-guide.png`.
- Reworked the homepage artwork to feature the castle and Aria.
- Reworked chapter navigation sizing and spacing for readable desktop and mobile layouts.
- Reworked lesson topic numbering into a centred, consistent number badge + content grid.
- On phones, the kingdom map becomes a vertical, touch-friendly chapter journey instead of a cramped scaled-down map.
- Existing chapter content, assessment questions, progress tracking, and learning interactions are retained.

Run `npm install`, `npm run build`, then `npm run dev` from this folder.
